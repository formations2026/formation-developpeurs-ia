# Planifier avant de coder

**Quand l'utiliser :** pour toute tâche de plus de deux fichiers

```text
Propose un plan en étapes vérifiables pour cette user story. Indique les fichiers touchés et les tests prévus. N'écris aucun code avant ma validation.
```

**À vérifier après :** relire le résultat, lancer `pytest`, et noter ici ce qui a dû être corrigé pour améliorer le prompt.
