# Déboguer

**Quand l'utiliser :** devant une trace d'erreur (nettoyée de toute donnée personnelle et de tout secret)

```text
Voici la trace, le code et le résultat attendu. Explique la cause avant de proposer un correctif. Donne trois hypothèses classées et comment vérifier chacune. Écris le test qui reproduit l'erreur.
```

**À vérifier après :** relire le résultat, lancer `pytest`, et noter ici ce qui a dû être corrigé pour améliorer le prompt.
