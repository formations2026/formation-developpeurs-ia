# Bibliothèque de prompts de l'équipe

Dix prompts éprouvés, versionnés à côté du code. Chacun contient **une contrainte** qui évite le défaut
le plus fréquent (inventer des fixtures, corriger au lieu de lister, modifier les tests…).

Règles de la bibliothèque :
- un prompt par fichier, avec « quand l'utiliser » et « à vérifier après » ;
- on améliore un prompt par pull request, comme du code ;
- aucun secret, aucune donnée réelle dans un prompt enregistré.
