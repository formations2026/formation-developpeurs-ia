# Relire un diff

**Quand l'utiliser :** avant d'ouvrir une pull request

```text
Relis ce diff comme un attaquant, puis comme un mainteneur. Classe les remarques par gravité, avec fichier et ligne. Ne corrige rien.
```

**À vérifier après :** relire le résultat, lancer `pytest`, et noter ici ce qui a dû être corrigé pour améliorer le prompt.
