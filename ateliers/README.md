# Les ateliers

Chaque atelier a la même structure : **objectif**, **étapes**, **critères de réussite**, **pour aller plus loin**,
et le corrigé est présenté par le formateur au débrief.

Règles communes :
- une branche par atelier : `git switch -c atelier-N-prenom` ;
- uniquement des outils autorisés par votre entreprise ;
- aucune donnée réelle, aucun secret : tout ce dont vous avez besoin est dans ce dépôt ;
- notez vos prompts efficaces : ils iront dans `prompts/`.

Le code de ce dossier est **volontairement imparfait** : il sert de support d'exercice.
Il est exclu des contrôles de qualité, et les identifiants qu'il contient sont fictifs.
